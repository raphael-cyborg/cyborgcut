# Estilos salvos

Um JSON por estilo: a base (um preset) e só o que muda. `exemplo.json` mostra o formato.

Os estilos de um cliente ficam em `<projeto>/estilos/` ou, pra valer em todo projeto da máquina,
em `~/.cyborgcut/estilos/`. Esta pasta é o terceiro lugar onde o motor procura, pra quem quiser
distribuir um estilo junto com a skill. Variáveis e opções: `references/estilo.md` ou
`python scripts/cyborgcut.py estilo opcoes`.
